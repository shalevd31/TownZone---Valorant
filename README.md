# טורניר ולוראנט | TownZone — אתר הרשמה

אתר הרשמה לטורניר ולוראנט של שרת הדיסקורד `discord.gg/townzone`.

ההרשמה **חובה** דרך משתמש הדיסקורד, והמערכת **דורשת** אימות ישיר של חשבון
Riot דרך Riot Sign-On (RSO) — התחברות אמיתית ל-Riot Client, לא רק "חיבור"
בהגדרות דיסקורד (ראו הערה חשובה למטה למה).

בתום ההרשמה מונפקים למשתמש שם משתמש (ה־tag של הדיסקורד שלו) וסיסמה
אקראית שמתחילה ב־`TZVAL`, ובוט הדיסקורד שולח אותם אליו בהודעה פרטית.
עם הפרטים האלה אפשר להיכנס לאתר בפעמים הבאות בלי לעבור שוב דרך דיסקורד
ובלי להתחבר שוב ל-Riot.

## הערה חשובה — למה RSO ולא "בדיקת חיבור" בדיסקורד

בגרסה ראשונה של האתר ניסינו לבדוק אם למשתמש יש Riot Games מחובר
בהגדרות → חיבורים של דיסקורד, דרך ה-API של דיסקורד. זה **כבר לא עובד**:
החל מ-10 ביולי 2026 דיסקורד הפסיקו להחזיר חיבורי Riot Games/League of
Legends דרך ה-API הציבורי (`/users/@me/connections`) — השינוי חד-צדדי
מצד דיסקורד ואין לו עקיפה. לכן המערכת עברה לאימות ישיר מול Riot עצמם
(RSO), שהוא בעצם אימות בעלות חזק יותר: המשתמש מתחבר ישירות עם שם
המשתמש והסיסמה של ה-Riot Client שלו במסך ההתחברות הרשמי של Riot (לא
אצלנו), ו-Riot מאשרת לנו את זהותו.

**מגבלה לדעת:** RSO לא מבדיל בין משחקי Riot – הוא מאמת שיש למשתמש
חשבון Riot בכלל (חשבון מאוחד לכל המשחקים, כולל Valorant), לא ספציפית
שהוא בעל גישה ל-Valorant. בדיקה ספציפית כזו (rank וכו') דורשת גישת
API נוספת ומוגבלת בהרבה שכנראה לא תהיה נגישה. עבור טורניר קהילתי זה
בדרך כלל מספיק.

## הרשאת Riot Sign-On (RSO) — נדרש לפני שהאתר יעבוד באמת

RSO **לא** זמין אוטומטית לכל מפתח — יש תהליך אישור:

1. היכנסו ל-https://developer.riotgames.com, קראו את המדיניות, ובקשו
   **Production API Key**. תצטרכו לתאר את הפרויקט — למשל: "אתר הרשמה
   לטורניר Valorant קהילתי בשרת דיסקורד, עם אימות שחקנים באמצעות
   Riot Sign-On לפני הרשמה לברקטים". אימות שחקנים בטורניר הוא
   שימוש מוכר ומאושר ע"י Riot (מפורש בתיעוד ה-RSO שלהם).
2. אחרי אישור ה-Production Key, תקבלו הזמנה לבקש גישת **RSO** ספציפית
   (Client ID + Client Secret נפרדים ל-RSO).
3. עד לאישור — כל שאר האתר (הרשמה עם דיסקורד, שליחת DM, כניסה עם
   שם משתמש/סיסמה) כבר בנוי ועובד; רק שלב אימות ה-Riot לא יהיה פעיל
   (יוצג "אימות Riot עדיין לא הוגדר").
4. התהליך יכול לקחת זמן ואין ערבות לאישור — זה תלוי ב-Riot.

## הרצה מקומית

1. **התקנת תלויות:**
   ```
   npm install
   ```

2. **יצירת אפליקציית דיסקורד** (כדי לקבל Client ID / Secret):
   1. היכנסו ל־https://discord.com/developers/applications ולחצו **New Application**.
   2. תנו שם (למשל "TownZone Valorant Turnir") וצרו.
   3. בתפריט הצד: **OAuth2 → General**. שם תמצאו את **CLIENT ID** ואת
      **CLIENT SECRET** (לחצו Reset Secret אם צריך לחשוף אותו).
   4. עדיין ב־OAuth2, תחת **Redirects**, הוסיפו:
      `http://localhost:3000/auth/discord/callback`
      (וכשתעלו לאוויר בכתובת אמיתית, הוסיפו גם את הכתובת שם, למשל
      `https://your-domain.com/auth/discord/callback`).

3. **יצירת הבוט** (כדי לשלוח הודעות פרטיות עם פרטי כניסה):
   1. באותה אפליקציה, לשונית **Bot** בתפריט הצד → **Add Bot** (אם עוד
      אין בוט).
   2. לחצו **Reset Token** / **Copy** כדי לקבל את ה־**Token** — זה
      הערך של `DISCORD_BOT_TOKEN` בקובץ `.env`. שימו לב: הטוקן מוצג
      פעם אחת בלבד, שמרו אותו במקום בטוח.
   3. אין צורך להפעיל Privileged Gateway Intents — שליחת הודעה פרטית
      לא דורשת אותם.
   4. **הזמנת הבוט לשרת:** בנו קישור הזמנה (או השתמשו בזה, מותאם ל־
      Client ID שכבר הגדרתם):
      ```
      https://discord.com/oauth2/authorize?client_id=<CLIENT_ID>&permissions=2048&scope=bot
      ```
      פתחו את הקישור, בחרו את שרת TownZone, ואשרו. הבוט חייב להיות
      חבר בשרת כדי שיוכל לשלוח הודעה פרטית לנרשמים (Discord דורש
      שרת משותף בין בוט למשתמש כדי לפתוח שיחה פרטית איתו).

4. **הגדרת Riot RSO** (אחרי שקיבלתם אישור מ-Riot, ראו סעיף למעלה):
   קבלו מ-Riot את ה-Client ID / Client Secret של ה-RSO Client, והגדירו
   ב-Riot Developer Portal את ה-Redirect URI:
   `http://localhost:3000/auth/riot/callback`
   (וגם את הכתובת הציבורית כשתעלו לאוויר).

5. **קובץ הגדרות:** העתיקו את `.env.example` לקובץ בשם `.env` ומלאו:
   ```
   DISCORD_CLIENT_ID=...          # מהעמוד ב-Developer Portal
   DISCORD_CLIENT_SECRET=...      # מהעמוד ב-Developer Portal
   DISCORD_REDIRECT_URI=http://localhost:3000/auth/discord/callback
   DISCORD_BOT_TOKEN=...          # מלשונית ה-Bot
   DISCORD_INVITE_URL=https://discord.gg/townzone
   RIOT_CLIENT_ID=...             # מ-Riot, אחרי אישור RSO
   RIOT_CLIENT_SECRET=...
   RIOT_REDIRECT_URI=http://localhost:3000/auth/riot/callback
   RIOT_REGION=europe
   SESSION_SECRET=<מחרוזת אקראית ארוכה כלשהי>
   ADMIN_USER=admin
   ADMIN_PASSWORD=<סיסמה משלכם>
   ```

   **אופציונלי — לחייב חברות בשרת לפני הרשמה:** הפעילו מצב מפתח
   (Settings → Advanced → Developer Mode) בדיסקורד, לחצו ימני על השרת
   TownZone → **Copy Server ID**, והדביקו אותו בתור `DISCORD_GUILD_ID`
   בקובץ ה־`.env`. אם משתנה זה ריק, הבדיקה מדולגת.

6. **הרצה:**
   ```
   npm start
   ```
   האתר יעלה בכתובת http://localhost:3000

## איך זה עובד

**הרשמה (חד־פעמית, חובה דרך דיסקורד + Riot):**
1. משתמש נכנס לדף הבית ולוחץ "הרשמה" → מועבר להתחברות OAuth2 של
   דיסקורד עם ההרשאות `identify`, `guilds`.
2. השרת בודק (אם `DISCORD_GUILD_ID` מוגדר) שהמשתמש חבר בשרת TownZone.
3. המשתמש מועבר להתחברות עם **Riot Sign-On** — מתחבר עם חשבון ה-Riot
   שלו במסך הרשמי של Riot. **לא ניתן להשלים הרשמה בלי זה.**
4. לאחר אימות שני הצדדים — המשתמש מאשר, נוצרים לו שם משתמש (ה־tag
   של הדיסקורד שלו) וסיסמה אקראית שמתחילה ב־`TZVAL`, הסיסמה נשמרת
   מוצפנת (scrypt) במסד הנתונים המקומי (`data/registrations.sqlite`),
   והבוט שולח לו הודעה פרטית עם הפרטים ועם כפתור לשרת.
   אם שליחת ה-DM נכשלת (למשל הודעות פרטיות חסומות אצל המשתמש), הפרטים
   מוצגים פעם אחת בדף ההרשמה כגיבוי.
5. משתמש שכבר נרשם ומנסה שוב פשוט רואה שהוא כבר רשום, עם קישור לכניסה.

**כניסה (בפעמים הבאות, בלי דיסקורד/Riot):**
- בדף `/login` המשתמש מזין את שם המשתמש והסיסמה שקיבל, ומגיע לעמוד
  אישי (`/account`) עם פרטי ההרשמה שלו.

## פאנל ניהול

בכתובת `/admin` (מוגן בסיסמה מ־`ADMIN_USER`/`ADMIN_PASSWORD`) יש טבלת כל
הנרשמים, אפשרות מחיקה, וייצוא ל־CSV.

## פריסה לאוויר (Hosting)

אפשר לפרוס על כל שירות שתומך ב־Node.js (Render, Railway, Fly.io, VPS
וכו'). דברים לזכור:
- עדכנו את `DISCORD_REDIRECT_URI` ו-`RIOT_REDIRECT_URI`, וגם ב-
  Developer Portal של דיסקורד ו-Riot, להיות הכתובת הציבורית שלכם
  (עם `https://`).
- ודאו ש-`data/` נשמר בין דיפלוימנטים (disk מתמשך) אם רוצים לשמור את
  ההרשמות; אחרת שקלו להחליף ל-DB חיצוני.
- שנו `SESSION_SECRET`, `ADMIN_PASSWORD` לערכים חזקים וייחודיים.
